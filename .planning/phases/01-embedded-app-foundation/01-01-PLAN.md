## Goal
Scaffold the Shopify App using the modern React Router template and verify the initial build.

## Tasks

Run the Shopify CLI scaffolding command:
`npm init @shopify/app@latest -- --template reactRouter --name ai-chatbot-app --path . --package-manager npm`
</action>
<acceptance_criteria>
- Directory contains a `package.json` with `@shopify/shopify-app-remix` or equivalent React Router dependencies.
- Directory contains an `app` folder with `root.tsx` or `routes`.
- `vite.config.ts` exists and includes the Shopify plugin.
</acceptance_criteria>
</task>

<task>
<read_first>
- app/root.tsx
</read_first>
<action>
Inject Polaris Web Components and App Bridge v4 CDN scripts into the `<head>` of the app.
Add:
```html
<script src="https://cdn.shopify.com/shopifycloud/app-bridge.js"></script>
<link rel="stylesheet" href="https://cdn.shopify.com/shopifycloud/polaris-web/v13/polaris-web.css">
<script type="module" src="https://cdn.shopify.com/shopifycloud/polaris-web/v13/polaris-web.esm.js"></script>
```
</action>
<acceptance_criteria>
- `app/root.tsx` contains the three script/link tags for App Bridge and Polaris.
</acceptance_criteria>
</task>

## Verification
